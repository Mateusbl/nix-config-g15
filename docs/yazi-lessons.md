# Yazi lessons

`yazi-learn` (from `home/yazi-learn.nix`) teaches Yazi in 12 short lessons, inside a throwaway
playground.

```bash
yazi-learn start      # fresh playground + Yazi (keep a second terminal for the lesson text)
yazi-learn lesson     # the current lesson; `yazi-learn lesson 3` for a given one
yazi-learn done       # mark it done; then `yazi-learn lesson` shows the next
yazi-learn quiz       # flashcards, mostly from lessons you finished
yazi-learn cheat      # every key; `yazi-learn list`, `answer`, `reset` also exist
```

- The playground is in `$XDG_DATA_HOME/yazi-learn/playground`, and progress is in `$XDG_STATE_HOME/yazi-learn`.
- `start` rebuilds the playground every time, so nothing you do there matters.
- Keys never come from memory. The lessons name Yazi *actions*, and the build looks up their keys in
  the installed Yazi's `keymap-default.toml` plus the additions in `home/yazi.nix`. The build
  fails if an action has no key.
- Everything under "Lessons" below is that generated output (`lessons.md`). After a Yazi update,
  regenerate it and replace that part:

```bash
nix build .#nixosConfigurations.g15.config.home-manager.users.mateus.my.yaziLearn.data
```

  The new text is in `result/lessons.md`.

**Live help inside Yazi:** the help action, `~` or `<F1>` (from the keymap, see below).
